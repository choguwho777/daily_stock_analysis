# Python·LLM 기반 주식 분석 리포트

주식 분석에 필요한 차트·재무 지표·뉴스를 수집하고, Gemini API를 활용하여 분석 리포트를 생성한 뒤 이메일로 전달하는 개인 프로젝트입니다.

이 저장소는 분석 리포트 생성에 집중하며, 매매 주문을 실행하지 않습니다. 규칙 기반 모의매매와 백테스트는 별도 저장소에서 관리합니다.

**주요 기능**
- 관심종목의 일봉 데이터 수집 및 기술적 지표 계산
- 이동평균선 골든크로스·볼린저밴드 이탈 조건으로 분석 대상 선정
- 주가·이동평균선·볼린저밴드·RSI 차트 생성
- 기업 재무 지표 및 최근 뉴스 수집
- 차트 이미지와 텍스트 정보를 이용한 LLM 분석
- 시장 상황과 종목별 분석을 HTML 이메일로 발송
- 종목별 분석 요청의 재시도 및 예외 처리

**LLM 입력 및 프롬프트 설계**

기술적 신호, 차트 이미지, 기업 정보·재무 지표, 최근 뉴스 헤드라인과 요약 일부를 함께 전달합니다.

프롬프트는 다음 기준으로 구성했습니다.

- 차트 분석은 첨부 이미지에 근거하도록 지시
- 확인되지 않은 뉴스·실적·수급 정보를 임의로 생성하지 않도록 지시
- 차트 분석·뉴스 해석·리스크·가격 시나리오 등을 항목별로 출력
- 이메일에서 읽기 쉬운 구조로 결과 생성
- 근거 제한 지시는 잘못된 생성을 줄이기 위한 장치이며, 출력의 정확성을 보장하지는 않습니다.

**주의사항**
본 프로젝트의 출력은 학습·연구 목적의 분석 자료이며 투자 권유가 아닙니다. 생성된 내용은 오류를 포함할 수 있으므로 원본 데이터와 대조해야 합니다.
